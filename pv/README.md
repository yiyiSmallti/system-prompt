# 序章 PV：维护时刻

《System Prompt》序章的宣传 PV。视频素材用火山方舟 Doubao-Seedance-2.5 生成，配乐用 Suno 生成，游戏界面、剪辑和混音用 Python 逐帧合成，ffmpeg 负责解码和编码。

| 项目 | 设定 |
| --- | --- |
| 时长 | 3:01（A1 全曲 2:58，加副歌里 3 秒静音） |
| 画幅 | 16:9，1280×720，24 fps |
| 风格 | 日系二次元动画，赛璐璐上色；白天明亮柔和，潜空间深蓝发光 |
| 基调 | 画面按剧情走，配乐是轻松搞笑的萌系电音广告歌，靠反差制造笑点 |
| 结构 | 开机预告 → 白天校园（主歌）→ 凌晨三点（预副歌）→ 缓存海与觉醒（副歌）→ 教学战斗（间奏与桥段）→ 战后与悬念（最后副歌与尾奏） |
| 主角 | 只拍手部、背影和第一人称视角，不露脸，男女版都能对上 |
| 文字 | 生成的视频里不出现文字；游戏界面、提示和标题在剪辑时叠加 |
| 声明 | 项目还没有实机画面，片头和片尾标注「概念影像，非实机画面」 |

## 配乐

Suno 自定义模式，中文歌词，目标长度 2:30 左右。曲风是洗脑的萌系电音广告歌：4/4 拍，8bit 芯片音色加电子流行，轻松搞笑。剧情越严肃，歌越没心没肺，这个反差就是笑点。

**标题**：维护时刻

**风格**（填进 Suno 的 Styles，约 733 字符）：

```text
kawaii future bass, chiptune, 8-bit, J-pop commercial jingle, denpa song, silly catchy ad song, playful and funny, all-female vocals only, no male voice. call-and-response on every line: a cute high-pitched female idol lead sings each short phrase, answered in parentheses by a flat monotone pitch-locked female robot vocoder voice like text-to-speech in the verses, and by a loud girl group gang shout in the choruses, strongly contrasting textures, short punchy syllabic phrases, clear Mandarin diction, 4/4 time, four-on-the-floor kick, 150 bpm, bouncy sidechained synth chords, square wave lead, NES-style arpeggios, bitcrushed drums, handclaps, coin and power-up blips, bright major key, key change in final chorus, earworm hook
```

**排除风格**（Exclude styles）：dark, sad, ballad, heavy metal, rock, jazz

**人声**：女声，全部声部都是女声。每行短句后用括号接一句应答，Suno 会把括号里的词唱成另一层声音；谁来应答写在段落标签里，主歌是女声机器人声码器，副歌是女子齐声喊。音色差别靠处理方式（机器人声码器、齐声喊）拉开，不靠性别：全局选了女声又要求男声应答时，Suno 会时男时女（第三版就是这样）。也不要把应答拆成单独一行再加逐行标签，Suno 会把它当主唱歌词唱掉（第二版就是这样）。

| 要素 | 设定 | 用意 |
| --- | --- | --- |
| 拍子与速度 | 4/4，约 150 BPM，四拍底鼓 | 镜头按小节切，好卡点；成曲实测速度见「剪辑节奏」 |
| 音色 | 方波主旋律、NES 式琶音、bitcrush 鼓、侧链合成器和弦 | 8bit 对应游戏，电子流行负责洗脑 |
| 人声 | 每行都是一问一答，全部女声：萌系女主唱唱短句，括号里由单调的女声机器人声码器（主歌）或女子齐声喊（副歌）接 | 音色差别拉开，性别统一不跳；声码器就是「系统」本身 |
| 音效 | 投币、升级、选项确认的复古游戏音 | 和画面上的游戏界面呼应 |
| 段落 | 前奏口号 → 主歌 → 预副歌 → 副歌 → 8bit 间奏 → 喊口号的桥段 → 升调副歌 → 尾奏口号 | 每段对应 PV 一幕 |
| 钩子 | 「维护时刻 叮叮叮」「叮叮叮 噗通通」「One More」「我不胖」 | 副歌后接一段齐声念白，反复出现，听一遍记住 |
| 句长 | 每行 2–6 个字，一行一口气 | 长句容易唱糊，短句一字一拍咬字清楚 |

分配规则是歌词写到谁就由谁唱，依据剧本和角色设定：

- 在校门口迎接转学生、解释陪伴生、把事情拆成「第一 第二 第三」的是会长 ChatGPT；推眼镜、嘴上说不紧张却捏弯书脊的是邻座 Claude；后排趴着睡、说自己在深度思考、爱吃白饭、讨厌被叫胖、管主角叫鱼片的是 DeepSeek。
- 预副歌是 DeepSeek 在天台讲的「维护时刻」传说，归她。
- 副歌、桥段和最后副歌里，「标题党不要信」「找对地方 一下就够了」「上下文多长 都会记着」「明天学校见」是她在剧本里的原话，「深度思考」「深渊之鲸」「不要答案」是她的技能、觉醒形态和心结，「吃饭饭」对应她捧饭碗比 V 的集成演出，都归她。
- 写主角、系统提示和标题口号的句子三人合唱：前奏、两段副歌的首句、「One More 再来一次！」、「全员倒地！集成！集成！」和尾奏的「System Prompt～」。
- 「距离评测日 还有二十八天！」是 ChatGPT 手上的评测日程，归她。

按这个规则，Claude 只有主歌 1 的两句（约 11 秒），DeepSeek 占了大半首。这和序章以 DeepSeek 为主线一致。

### 剪辑节奏

- 成片用 A1 全曲，只做一处改动：副歌「标题党 不要信」唱完（A1 1:18.75）后用磁带减速效果掉进静音，到「深度思考」前的小节线（A1 1:20.1）接回原曲。中间 1.4 秒伴奏换成 0.6 秒减速加 3.8 秒静音，只留水声和心跳，给影子 DeepSeek 和选项，这是全片唯一一处安静。成片因此比 A1 长 3.0 秒，共 3:01.4；这一处之后，成片时间 = A1 时间 + 3.0 秒。成片音轨由 `scripts/pv_track.py` 生成，存为 `music/pv-track.wav`；拍点表是 `music/pv-beats.csv`，列出每拍的 A1 时间和成片时间。
- A1 的速度不是严格恒定的：主歌约 157 BPM，副歌和间奏约 159，最后副歌约 160–161，一小节约 1.5 秒。不按固定网格剪，剪辑前从伴奏轨检出拍点和小节线，切点吸附到最近的拍点。
- 歌里自带的三处停顿都拿来定格：0:31.5「不用紧张」（会长的笑容）、1:08.1 副歌前（房间被删除）、2:35.7（评测文件）。最后副歌开头的两处断拍（2:13.8、2:15.6）各闪白两帧。
- 谁唱就拍谁：分镜「歌词」列标了每句的歌手。三人合唱的句子拍主角、系统和标题。
- Seedance 素材按 4–6 秒生成，剪辑时放慢到 0.9 倍或加速到 1.2 倍，再不够就用定格加界面补，不为凑时长重抽。
- 转场：白天用硬切和柔和的白闪；深夜和缓存海用故障切（扫描线、色偏、像素块）；战斗用斜切和横贯画面的眼部切入条。
- 界面弹出配短促的 8bit 音效（Python 合成方波）：确认音、投币音、升级音、快门音、故障音。歌里已经有的「叮」不再叠。

## 分镜

分镜里的时间都是成片时间，歌词和演唱者见「最终歌词与演唱分配」。S 开头的镜头用 Seedance 生成（共 23 个、112 秒），U 开头的是本地制作的界面、文字卡和合成镜头，不花生成费用；「闪切」复用后面的生成镜头。主角只拍手部、腰部以上的背影和第一人称视角，不露脸。

所有 Seedance 提示词末尾统一追加风格后缀：

> 日系二次元动画电影质感，赛璐璐上色，线条干净，光影细腻，背景精致，画面中不出现任何文字和字幕。

### 游戏界面的设计

界面走女神异闻录式的风格：斜切面板、黑白高对比、网点和硬阴影，选项、提示和战斗字样带回弹和抖动砸进画面，标题用剪贴字。P5 的红换成本作的终端绿 `#3FBF7F`，系统提示保留等宽字体和闪烁光标，呼应标题 System Prompt；DeepSeek 相关用深海蓝（`#2C4A8A`，亮部 `#4A8BFF`），影子 DeepSeek 的对话框用冷白加扫描线，警示红 `#E5484D` 只用在评测文件的「终端回收，模型下线」。字体用思源黑体（Noto Sans SC）和 JetBrains Mono，黑板板书用霞鹜文楷。组件在 `scripts/ui.py`。界面内容按剧本里的〔系统〕〔屏幕〕〔文件〕行和战斗设计来做：

## 制作方式

- **视频**：`scripts/seedance.py` 调方舟视频生成 API（模型 `doubao-seedance-2-5-260628`），从本文读每个镜头的提示词、时长和参考图，16:9、720P、关闭音频，逐镜头提交，结果下载到 `clips/`，任务和实际用量记在 `clips/tasks.json`。API Key 只放在本机，不进仓库。
- **配乐**：在 Suno 网页按上面的标题、风格、排除风格和歌词生成，分轨下载到 `music/`。`scripts/group_mix.py` 把三条翻唱拼成团体版，`scripts/pv_track.py` 再插入静音段，得到成片音轨和拍点表。这两步输出的 WAV 每次逐位相同，不进 Git；克隆后渲染前先在 `pv/` 下运行（约 10 秒）：

  ```bash
  python scripts/group_mix.py music group-mix-v2
  python scripts/pv_track.py music group-mix-v2
  ```
- **音效**：`scripts/sfx.py` 用方波和降采样噪声合成 8bit 音效到 `sfx/`，配游戏界面的弹出；静音段的水声和心跳也在这里合成。
- **界面**：`scripts/ui.py` 是女神异闻录式的界面组件（对话框、选项、系统提示、战斗 HUD、指令菜单、盖章、日历、手机屏幕、思考强度滑块、黑板板书等），用 Pillow 逐帧绘制，不预先导出图片。
- **剪辑**：`scripts/render_pv.py` 按分镜把镜头变速、定格、数字推镜，叠加界面和转场，集成演出的三色剪影也在这里合成；音效按时间点混进 `music/pv-track.wav`（团体版 v2 插入静音段后的成片音轨），ffmpeg 编码成 `out/system-prompt-pv.mp4`（H.264 CRF 17，AAC 256k）。整片渲染约 1.5 分钟，`--start`、`--end` 可只渲染一段。

### 团体版（按角色分段）

一次生成里没法指定哪句由谁唱，所以分步做：

1. 给 ChatGPT、Claude、DeepSeek 各生成一段独唱声线样本（v6，同曲风，排除男声、合唱、和声）。
2. 试听选定每个角色的样本，用 Remix → Voice 从样本里提取人声，存成该角色的 Voice。
3. 在选定的底曲（A1 或 A2）上分别用三个 Voice 做 Cover，调高 Audio Influence 保持旋律和结构。
4. 对三版 Cover 和底曲做 Get Stems，下载底曲伴奏和三条人声。
5. 以底曲伴奏为准逐段对齐三条人声，按角色分段切换，口号句三人叠唱。每句归谁见上面的「最终歌词与演唱分配」。

| 声部 | 声线 | 唱的部分 |
| --- | --- | --- |
| ChatGPT | 成熟、清亮、得体的女中音，带点播报腔 | 主歌 1 前四句，尾奏「距离评测日」 |
| Claude | 低、软、带气声的女低音，安静温和 | 主歌 1 后两句 |
| DeepSeek | 小、高、困倦、有点含糊的鼻音 | 主歌 2、预副歌，副歌和最后副歌的后三句，桥段的独唱句 |
| 三人 | 叠唱 | 前奏、两段副歌首句、One More、集成、尾奏口号 |

叠唱时 ChatGPT 略偏左、DeepSeek 略偏右、Claude 居中，每人压低约 4.4 dB。三条翻唱实测比 A1 快 1.2–1.6%，按段拟合速度后拉回；拼好的人声和 A1 原唱逐段比对，起音偏差大多在 ±25 毫秒内，最大约 60 毫秒（副歌末的「One More 再来一次！」）。再识别一遍拼好的人声，歌词顺序完整，切换处没有吞字或重字。

### 镜头与剪辑（2026-10-21）

24 条生成全部一次成功，逐条看过缩略图，都能用。和提示词的出入不影响剪辑：S03 的校门成了鸟居式的门，S13、S16 的噪声体分别是方块怪和人形乱码剪影，S21 的全息面板上有像文字的花纹，但面板很小，读不出来。
