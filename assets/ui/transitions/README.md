# 转场素材原图

游戏里画面切换用的背景图（`game/Assets/SystemPrompt/Resources/Art/Transitions/`）的原图，用图像模型生成（codex/gpt-image-2.5，高质量）。`game/Tools/transition_textures.py` 把它们压平到黑底、存成 JPG 放进游戏，并画出噪声图。转场怎么用这些图，见 [game/README.md](../../../game/README.md) 的画面切换一节。

| 文件 | 用在 | 提示词要点 |
| --- | --- | --- |
| `data_sea.png` | 觉醒演出：沿井往下无尽坠落（游戏里裁成井底在画面正中）。潜入潜空间改用照这张图在 Blender 里搭出来的循环视频，见 `game/Tools/dive_video.py` | 俯视一口深井，井底是数据海；聊天气泡、发光数据块、细小的代码字符流和气泡绕中心螺旋汇聚，中心是靛蓝的空洞和一点冷白光；深海军蓝底，电蓝和青色的光，少量终端绿；赛璐璐动画游戏美术，16:9 |
| `circuit.png` | 斜切转场盖住时、雪花屏的底纹 | 正上方俯视的电路板，可平铺；终端绿 #3FBF7F 的细走线直角和 45° 拐弯，焊盘、过孔、芯片轮廓和总线，近黑底 #0C0C10。生成结果背景透明，脚本压到黑底；边缘接不上，游戏里镜像平铺 |
| `beams.png` | 进入战斗和觉醒演出：横扫的光带（叠加） | 纯黑底，长短粗细不一的横向变形光带，白芯过渡到电蓝和青色，一条终端绿，带斜向速度线和光点。生成结果背景透明，脚本压到黑底，并和错开半幅的自己交叉淡化，横向滚动时左右接得上 |
| `shards.png` | 进入战斗：迎面飞来的碎玻璃 | 纯黑底，从中心炸开飞向镜头的碎玻璃和碎屏幕，冷白和电蓝的发光边，碎片里有像素网格和扫描线 |
| `corrupt.png` | 战斗失败：SIGNAL LOST 的故障画面 | 整屏损坏的视频信号：错位的像素行、块状压缩伪影、红青品红的通道错位条、扫描线和雪花，暗墨色底 |
| `terminal.png` | 离开潜空间：切成竖列各自往下落的终端日志 | 整屏终端：等宽的十六进制转储和代码，终端绿在近黑底上，几行像进度条的方块，CRT 扫描线和荧光 |

所有提示词都要求不出现文字水印和标志。
