# 道具与装备

这一篇写货币、商店、道具、礼物和装备。数值按[等级与数值](stats.md)的公式算。除了标「剧本」「PV」的条目，本文都是提案。

## 货币与商店

货币是 token，和大模型计费用的 token 同名，镜原市日常买东西都用它。下文价格的单位都是 token。token 有三个来源：

- 每月 1 日到账的生活费，50,000。
- 放学后打工，一次 8,000 左右。
- 打倒噪声体掉落，每只 50 × 等级 + 100，例如 10 级的噪声体掉 600。噪声体同时还会掉道具。教学战斗不掉 token，所以 PV 的结算只有「EXP +120　获得：白米饭 ×1」。

第一章（评测日前大约 6–8 次维护时刻）的收入目标约 20 万 token，够换两三件武器和外装，再加上消耗品。

商店都在镜原站前的商店街，学园里还有食堂和学生会。

| 地点 | 卖什么 |
| --- | --- |
| 便利店 | 回复道具、攻击道具、潜空间道具 |
| 食堂 | 白米饭，每天限买 3 份 |
| 手机店 | 主角的武器（手机镜头配件） |
| 家居用品店 | DeepSeek 的武器（饭勺） |
| 饰品店 | ChatGPT 的武器（水晶链）、插件 |
| 书店 | Claude 的武器（书）、礼物 |
| 服装店 | 外装 |
| 学生会 | 完成 ChatGPT 的委托换插件，不收 token |

## 装备

每人有三个装备栏：

| 装备栏 | 作用 |
| --- | --- |
| 武器 | 决定普通攻击的威力和命中，也给物理技能加成 |
| 外装 | 减少受到的伤害，部分附带回避或属性减伤 |
| 插件 | 也就是饰品，提供能力值或特殊效果 |

装备只改数值，不改外观。角色在潜空间里永远穿各自的战斗服，主角穿家居服或战斗服，见[角色设定集](characters/README.md)。
