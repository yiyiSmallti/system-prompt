# 《System Prompt》序章：维护时刻

2026-10-22

## 概要

序章用一天一夜讲完主角转学、遇见三位AI同学、第一次进入潜空间，并以DeepSeek觉醒入队收尾，预计游玩时长50到70分钟。在潜空间里，主角先遇见DeepSeek，两人一起绕到灯塔找出口的方向，觉醒之后再一起下到深层走到出口；两段潜空间探索约20到30分钟。

| 项目 | 内容 |
| --- | --- |
| 时间 | 4月7日（周二）早晨、上课、午休、放学后、晚上 → 4月8日凌晨 → 4月8日早上 |
| 舞台 | 镜原市，私立潜川学园；潜空间「缓存海」 |
| 登场 | 主角（玩家命名，可选男女，下文记作「我」）、ChatGPT、Claude、DeepSeek |
| 入队 | DeepSeek（隐者 Coop Rank 1） |
| 教学 | 对话选项、Coop提示、潜空间探索（遇敌与先制攻击、推箱子与反射板机关、维护进度）、基础战斗、弱点「对抗样本」与One More |

**剧本格式**：`【场景】`为舞台说明，`角色：`为台词，`▶`为玩家选项，`〔系统〕`为界面提示，`〔输入〕`由玩家打字填写，`〔CG〕`为全屏过场图（盖住场景和立绘，后面的台词在图上继续，到换场景或进战斗为止）。旁人用第三人称指代主角时写作「他／她」，按玩家选择的性别显示。选项后的分支台词标`（选1）``（选2）`；按前面某个选择变化的台词标`（若……）`，分支最后都回到主线。玩家在天台给 DeepSeek 起的称呼下文记作「○○」，按输入的内容标`（起「……」）`的台词只在起了那个称呼时出现。潜空间里标`（右上角播报）`的段落由 DeepSeek 在画面右上角说，不打断探索，只放她的台词。

## 场景4：维护时刻
